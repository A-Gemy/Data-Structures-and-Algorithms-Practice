# Jagged Array Problems

This folder contains 7 C# console problems focused on practicing Jagged Arrays.

The goal of this category is to understand how to store and process data where each row can have a different number of elements.

## Problems

- JA-01 Store marks of students in multiple subjects
- JA-02 Store sales data by quarter
- JA-03 Dynamic seating arrangement in a classroom
- JA-04 Daily sales for different products
- JA-05 Flight seat reservations
- JA-06 Survey responses
- JA-07 City temperature data

## How to Run

1. Open `Data-Structures-and-Algorithms-Practice.sln`
2. Select any project inside `05-Jagged-Array`
3. Set it as the startup project
4. Run it from Visual Studio
