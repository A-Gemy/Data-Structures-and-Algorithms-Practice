# BitArray Practice

This folder contains practice problems focused on using `BitArray` in C#.

## Problems

1. **BA-01 - Smart Home Light Control**
   - Control the state of multiple lights using a `BitArray`.

2. **BA-02 - User Survey Results**
   - Store Yes/No survey responses using bits.

3. **BA-03 - Theater Seat Bookings**
   - Track booked and available theater seats.

4. **BA-04 - Weekly Schedule**
   - Represent busy and free days using a `BitArray`.

5. **BA-05 - Password Strength Checker**
   - Track uppercase, lowercase, digit, and special-character requirements.

6. **BA-06 - Password Policy Enforcement**
   - Check whether a password satisfies all required rules.

7. **BA-07 - Traffic Light System**
   - Represent and update traffic-light states for intersections.

8. **BA-08 - Voting System**
   - Record Yes/No votes and count voting results.

9. **BA-09 - Bit Status Counter**
   - Count the number of `true` and `false` bits.

10. **BA-10 - BitArray AND Operation**
    - Perform a bitwise AND operation between two `BitArray` objects.

11. **BA-11 - BitArray to Integer**
    - Convert binary data stored in a `BitArray` into an integer.

12. **BA-12 - Integer to BitArray**
    - Convert an integer into its binary representation using a `BitArray`.

## Concepts Practiced

- Creating and accessing `BitArray` objects
- Setting and updating individual bits
- Iterating through bits
- Counting `true` and `false` values
- Bitwise operations
- Binary representation
- Left shift operator (`<<`)
- Converting between integers and binary data
