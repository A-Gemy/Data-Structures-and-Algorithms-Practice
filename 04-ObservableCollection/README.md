# ObservableCollection Problems

This folder contains 7 C# console problems focused on practicing ObservableCollection.

The goal of this category is to understand how ObservableCollection notifies when items are added, removed, replaced, moved, or cleared, which is useful for dynamic data and UI updates.

## Problems

- OC-01 Dynamic list of students in a classroom
- OC-02 Shopping cart for an e-commerce app
- OC-03 Real-time stock prices
- OC-04 Task management system
- OC-05 Live chat application
- OC-06 Dynamic weather updates
- OC-07 Real-time notification system

## How to Run

1. Open `Data-Structures-and-Algorithms-Practice.sln`
2. Select any project inside `04-ObservableCollection`
3. Set it as the startup project
4. Run it from Visual Studio
