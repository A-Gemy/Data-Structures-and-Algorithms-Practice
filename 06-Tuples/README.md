# Tuples Problems

This folder contains 5 C# console problems focused on practicing tuples and ValueTuple.

The goal of this category is to understand how to group related values together and return multiple values from methods without creating a full class.

## Problems

- TP-01 Return multiple values from a function
- TP-02 Track player stats in a game
- TP-03 Store and compare employee details
- TP-04 Return success or failure from a function
- TP-05 Simplified address representation

## How to Run

1. Open `Data-Structures-and-Algorithms-Practice.sln`
2. Select any project inside `06-Tuples`
3. Set it as the startup project
4. Run it from Visual Studio
